Ответы на вопросы:

1. Dart — статически типизированный язык: тип переменной известен на этапе компиляции и проверяется компилятором.
Python — динамически типизированный: тип определяется во время выполнения, и ошибки типов всплывают только при запуске.

Практическое преимущество Dart: ошибки типов ловятся ещё до запуска программы. Это ускоряет разработку (IDE подсказывает, автодополняет, безопасно переименовывает), уменьшает количество багов в рантайме и делает код понятнее для чтения.

2. String — non-nullable тип: переменная обязана содержать строку и не может быть null.
String? — nullable тип: переменная может содержать строку или null.

3. «Договорённость» в Python не проверяется — любой другой разработчик может случайно переприсвоить значение, и компилятор промолчит.
final — это гарантия, проверяемая компилятором.

4. Позиционный параметр передаётся по порядку следования. Именованный — по имени, порядок не важен, и при required его обязательно нужно указать.

Пример:
// Позиционный
String greet(String name, int age) => 'Привет, $name ($age)';
greet('Иван', 20);            // порядок важен

// Именованный
String greet2({required String name, int age = 18}) =>
    'Привет, $name ($age)';
greet2(name: 'Иван');               // ок, age по умолчанию
greet2(name: 'Иван', age: 20);      // порядок не важен
greet2(age: 20, name: 'Иван');      // тоже ок
